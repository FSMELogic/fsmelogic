The Foundation

Security you can verify,
not security you're promised.

Every guarantee in Stratum is structural. It doesn't ask untrusted code to behave; it removes the ability to misbehave.

Capability security

A program can only do what you grant at start. A nested call can never gain a permission its caller lacked. Bounds are SMT-proved, not just tested.

Rejects trojans at load

Import a vendor module under an empty capability ceiling. If a tampered version declares one effect outside that ceiling, it's refused before a single instruction runs.

A detector code can't touch

The FSME anomaly detector runs inside the runtime, where application code cannot reach or disable it. Sabotage that passes range checks still gets caught.

Byte-identical engines

The same source produces byte-identical output on the interpreter and the WebAssembly engine. The code you audit is exactly the code you run.

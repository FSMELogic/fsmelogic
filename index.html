What Stratum Is

A tool, not a promise.

A hammer builds a house or breaks a window, and the toolmaker is neither the carpenter nor the vandal. Stratum is the same kind of thing: a substrate that gives you structural guarantees, so what you build on top of it is bounded by construction. What you build is yours.

So we are precise about what this is. We did not ship "AI safety." We did not ship a "system monitor." We shipped the language and runtime that governed gateways, forensic analyzers, and bounded control systems get built on. Below is what the tool actually gives you.

Capability security

A program can only do what you grant at startup. A nested call can never gain a permission its caller lacked. These bounds are SMT-proved, not just tested.

Rejects tampering at load

Import a vendor module under an empty capability ceiling. A tampered version that declares even one effect outside that ceiling is refused before a single instruction runs.

An in-runtime detector

The built-in detector watches from inside the runtime, where the watched code cannot reach or disable it. Sabotage that passes ordinary range checks still surfaces as a structural shift. Stratum Pro sharpens this with a higher-precision kernel.

Byte-identical engines

The same source produces byte-identical output on the interpreter and the WebAssembly engine. The code you audit is exactly the code that runs.

AI Governance · Built on Stratum

Governor

A gateway that sits in front of a local AI. Every request and answer passes through it on your machine, is allowed or blocked by deterministic rules, and leaves with an Ed25519-signed record.

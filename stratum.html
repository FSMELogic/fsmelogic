The Language

Install. Grant.
Run.

Stratum is a statically typed, actor-based language where whole classes of failure are prevented by the execution model, not caught after the fact. A program can only do what you grant it. You can be running it in the next two minutes, free.

Quick Start

Install. Write. Run.

01 · Installation

$ pip install stratum-lang

One install works on Windows, macOS, and Linux. Python 3.9+. MIT licensed, free forever, no sign-up. View the package on PyPI ↗

02 · Your first program

hello.st 
module hello;

fn main() -> Unit effects [console] do
    let a = 5;
    let b = 3;
    print("Sum:", a + b);
    ()
end fn

Every function declares the effects it uses. This one needs the console, so it says so.

03 · Grant it, run it

$ stratum --grant console hello.st

There is no ambient authority. The program can print because you granted console on the command line, and it can do nothing you did not grant.

04 · Prove it on both engines

$ stratum --grant console --engine=ast  hello.st
$ stratum --grant console --engine=wasm hello.st

The same source produces byte-identical output on the AST reference engine and the WebAssembly engine. The code you audit is exactly the code that runs.

Writing it with an AI? The whole language fits in one context pack. Paste LLM_CONTEXT_PACK.md (ships with the package) into any capable LLM and it writes correct Stratum with no prior training on the language. That is the point: the runtime, not the model, enforces the guarantees.

No Ambient Authority

A program can only do
what you grant.

Every capability is off until you turn it on with --grant. A nested call can never gain a permission its caller lacked.

Stratum Basic · Free

What the free tier is.

Not a demo. The full language, MIT licensed, on PyPI.

The full language

Statically typed, actor-based, with isolated actors and no shared mutable state. Both execution engines included.

Capability security

Effects are declared per function and narrowed on every operation. What you did not grant cannot happen.

Byte-identical engines

The AST reference engine and the WebAssembly engine produce identical output for the same source. What you test is what you ship.

Open-core detector

A built-in anomaly detector watches from inside the runtime, where the watched code cannot reach or disable it.

The Flagship

Stratum Pro.
The same language, in production.

Pro is not a different Stratum. It is the same source and the same engines, plus the pieces a regulated deployment is required to have, and a vendor who signs an SLA. What you prototype on the free tier graduates to Pro unchanged.

High-precision kernel

The FSME Proprietary Edge Kernel catches stealth attacks the standard detector misses, with far fewer false alarms.

Cryptographic identity

Ed25519 attestation on every module, so you can prove who authored it and that it was not altered.

Fleet controls

Per-device license verification and telemetry export for managing Stratum across a fleet.

AI cognitive governance

Wrap a model so a jailbreak is refused by the runtime structurally, rather than by the model's good behaviour.

No key-person risk. If a Pro subscription lapses, or we disappear tomorrow, the runtime reverts cleanly to Stratum Basic and your embedded system keeps running. Your plant never depends on our uptime, or on us existing.

Proof Artifact 01

The water-treatment gateway

A dosing gateway embeds an unaudited third-party module under an empty capability ceiling. The trojaned twin is rejected at load. Sabotage that passes range validation is caught by the runtime detector, and the actor quarantines itself. One command, PASS or FAIL, runnable on your own machine.

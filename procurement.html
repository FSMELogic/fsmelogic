Security Posture

Data Sovereignty & Security Architecture

Zero Data Exit Policy

Client telemetry data is processed exclusively on founder-operated, air-gapped hardware in Edmonton, Alberta, Canada. No client data is transmitted to third-party cloud services, external APIs, or any public-facing infrastructure at any stage of analysis.

  • All analysis conducted on physically isolated, offline hardware
  • Full-disk encryption on all analysis systems
  • Zero open router ports — no inbound or outbound network traffic during processing
  • SHA-256 cryptographic custody receipt provided at intake and delivery
  • Client raw data files securely deleted following report delivery

Zero-Cloud Architecture

The FSME Predictive Integrity Engine has no cloud dependencies, no SaaS infrastructure, and no public-facing application endpoints. Software is delivered as a fully compiled, offline-capable Windows binary. License activation is performed via manual alphanumeric key — no server ping required.

  • No internet connection required for software operation
  • No telemetry or "phone home" mechanisms in any FSME software product
  • No third-party cloud processors handle client data at any point
  • Compatible with air-gapped OT/SCADA network environments

Defense & Aerospace Compliance Readiness

For defense contractors and aerospace clients handling export-controlled (ITAR) or Controlled Unclassified Information (CUI) telemetry, the FSME architecture satisfies zero-trust data handling requirements by design. There is no data egress pathway, no third-party data processor, and no cloud exposure at any stage.

  • CUI telemetry can be processed without cloud exposure
  • Air-gapped edge-compute delivery model eliminates supply chain risk
  • NDA executed prior to any data transfer upon request
  • Forensic reports include SHA-256 chain-of-custody documentation
  • Suitable for SWaP-C constrained environments via edge-compute deployment
